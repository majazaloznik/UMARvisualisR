# Gap between an axis and its numeric labels, in csi lines

The `mgp[2]` offset the numeric axis labels are drawn at, and the same
allowance the margin calculations make for them. One value, three uses:
[left_axis_labels](https://majazaloznik.github.io/UMARvisualisR/reference/left_axis_labels.md)
draws with it,
[left_axis_label_width](https://majazaloznik.github.io/UMARvisualisR/reference/left_axis_label_width.md)
and
[right_axis_label_width](https://majazaloznik.github.io/UMARvisualisR/reference/right_axis_label_width.md)
reserve space with it.

## Usage

``` r
axis_label_gap()
```

## Value

numeric scalar
