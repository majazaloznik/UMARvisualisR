# Calculate smallest gap between labels

takes x positions and labels and calculates the smallest gap in the
series. the unit is the width of the letter "m"

## Usage

``` r
calculate_smallest_gap(x_positions, x_labels)
```

## Arguments

- x_positions:

  vector of x positions

- x_labels:

  character vector of x labels

## Value

size of smallest gap in "m" width
