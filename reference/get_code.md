# Generate reproducible code for a chart

Returns the full
[`prep_chart()`](https://majazaloznik.github.io/UMARvisualisR/reference/prep_chart.md)
call with all parameters explicitly specified, so the chart can be
reproduced or modified.

## Usage

``` r
get_code(chart)
```

## Arguments

- chart:

  an object of class "umar_chart" from
  [prep_chart](https://majazaloznik.github.io/UMARvisualisR/reference/prep_chart.md)

## Value

character string with the code (also printed to console)
