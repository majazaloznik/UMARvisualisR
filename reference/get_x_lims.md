# Get x limits from the data

Used after the data has been cut to user xlims, this returns the actual
first and last date in the datapoints

## Usage

``` r
get_x_lims(datapoints)
```

## Arguments

- datapoints:

  list of dataframes from
  [prep_data](https://majazaloznik.github.io/UMARvisualisR/reference/prep_data.md)

## Value

date range
