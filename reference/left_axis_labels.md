# Draw left axis labels

Draw left axis labels

## Usage

``` r
left_axis_labels(unit, axis_positions, axis_labels, y_lab_lines)
```

## Arguments

- unit:

  unit usually from
  [left_axis_label_width](https://majazaloznik.github.io/UMARvisualisR/reference/left_axis_label_width.md)

- axis_positions:

  axis label positions usually from
  [left_axis_label_width](https://majazaloznik.github.io/UMARvisualisR/reference/left_axis_label_width.md)

- axis_labels:

  labels from
  [left_axis_label_width](https://majazaloznik.github.io/UMARvisualisR/reference/left_axis_label_width.md)

- y_lab_lines:

  number of margin lines from
  [left_axis_label_width](https://majazaloznik.github.io/UMARvisualisR/reference/left_axis_label_width.md)

## Value

nothing, draws axis title and labels
