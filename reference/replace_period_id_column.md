# Replace the period_id column with the correctly alligned date

Replace the period_id column with the correctly alligned date

## Usage

``` r
replace_period_id_column(df, position = "c")
```

## Arguments

- df:

  dataframe with period_id column

- position:

  defaults to "c", but "l" and "r" are also valid

## Value

df with same number of cols
