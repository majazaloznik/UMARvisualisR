# UMAR colour palette function

Returns colour(s) from the UMAR corporate graphical identity palette.
Colour names are rdeca, roza, siva, temno_modra, turkizna, zelena,
vijolicna, sinja, gridlines and emph. The last two are grays for
gridlines, axes and the like and for emphasising the 100/0 gridline.

## Usage

``` r
umar_cols(...)
```

## Arguments

- ...:

  optional colour names.

## Value

hex value of relevant colour(s)
