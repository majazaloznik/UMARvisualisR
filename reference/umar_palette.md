# Get or set the active UMAR colour palette

The default is the UMAR-style palette used in all official publications.
The alternative is the Janez-style colour blindness palette. Set it once
per session!

## Usage

``` r
umar_palette(palette)
```

## Arguments

- palette:

  "default" or "Janez" (or "janez"). Omit to get current value.

## Value

active palette name (invisibly when setting)
