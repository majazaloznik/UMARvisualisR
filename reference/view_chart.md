# Plot a prepared chart to the current device

Takes a chart object from
[prep_chart](https://majazaloznik.github.io/UMARvisualisR/reference/prep_chart.md)
and renders it to the current graphics device.

## Usage

``` r
view_chart(chart)
```

## Arguments

- chart:

  an object of class "umar_chart" from
  [prep_chart](https://majazaloznik.github.io/UMARvisualisR/reference/prep_chart.md)

## Value

invisible chart object (for piping)
